## 一、已经定下的三条

| 项 | 结论 |
| --- | --- |
| 快捷键 | `Ctrl+Shift+S`：有选中存选中，没选中存整段草稿 |
| 位置 | 默认右下角，**可拖动**，记住位置；收起时透明度更低（比 30% 更淡） |

### 头部竞品的真实问题（都有 issue 号，不是我猜的）

- **#12（closed）**：用 `MutationObserver` 扫 `document.body`，找到「设置」按钮旁边插入口，结果把整个账户菜单克隆成死副本——菜单点不动、点外面不关、Esc 也不关。装了 DS Bot 必现。
- **#10（closed）**：同样的 DOM 注入换了位置，最后改成设置页里的独立面板。
- **#15 / #14（open）**：README 写着「人格管理」「技能管理」入口，实际面板是死代码，用户打开只有 4 项。
- **#6（closed）**：每次运行注入一段「你是词库助手」的系统提示词，用户直接提「请不要污染系统提示词」。
- **#7（closed）**：desktop 启动进恢复模式，`patch: entry hindsight not found`。
- **#8（closed）**：AI 润色把整段输出清成空串。

这些不是功能多少的问题，是**侵入别人的界面**和**接管全局状态**带来的故障面。

### 第二名的短板

`dsh-quick-prompts` 是「指令胶囊」，不是「收藏」。它的胶囊排在输入框上方，**永久占据一行高度**；只能存「能一条发出去的指令」，存不了一段素材、一个模板、半句话；没有搜索，只能按分类点。

## 三、我们的差异点，逐条可验

| 维度 | dsh-prompt-library | dsh-quick-prompts | 本插件 |
| --- | --- | --- | --- |
| 占版面 | 侧栏一个入口 + 全屏居中面板 | 输入框上方一行胶囊，永远在 | 浮层一枚 24px 圆点，不参与布局，可拖动，可淡到几乎看不见 |
| 存一条要几步 | 开侧栏 → 开面板 → 新建 → 粘贴 → 填标题/标签 → 保存（5 步，离开输入位置） | 开管理弹窗 → 新建 → 粘贴 → 保存（4 步） | 在草稿上按 `Ctrl+Shift+S`（1 步，不离开光标） |
| 取一条要几步 | 开面板 → 搜索 → 点插入 → 选插入/覆盖/发送 | 点胶囊 → 预览 → 同步/发送 | 点圆点 → ↑↓ 选 → 回车插入；或 `Ctrl+Shift+P` 打开面板 |
| 插入后 | 追加到输入框 | 同步或直接发送 | **插到光标处，面板自动关，焦点回输入框**，不打断 |
| 故障面 | DOM 注入史、系统提示词注入、AI 润色、DB | 常驻 UI | 不碰 DOM、不改系统提示词、无 AI 调用、无数据库 |
| 体积 | 仓库 23 MB（含图与锁文件） | 未知 | 预算 < 30 KB，零运行时依赖 |
| 大库检索 | 有搜索 | 无 | 有（模糊匹配标题与正文） |

### 一句话定位

**别人做的是「提示词管理系统」，我们做的是「随手存一下」。**

### 明确不跟的

- 不做标签树、导入导出向导、回收站、人格、AI 润色、从提示词生成 Skill。头部竞品这些都有，跟它比就是进入它的战场。
- 不做侧栏、不做设置页、不做常驻横条。
- 第一版不做云同步。

### 必须守住的底线（对抗竞品的强项）

- 搜索必须真的快：500 条以内，输入即过滤，无延迟感。
- 不能丢数据：原子写 + 损坏文件改名留底，和 dsh-todo-bar 一样。
- 插入不能丢内容：草稿里已有文字时，插入是**加在光标处**，不是覆盖；覆盖要显式按 Alt。
- 不能挡键盘：面板打开时 Esc 关、↑↓ 移动、回车插入，焦点不跑到别处。

## 四、第一版范围

做：

- 浮层圆点（24px，可拖，位置持久化，透明度 0.35 收起 / 0.9 悬停）
- 展开卡片 320px：搜索框 + 两个分档（此项目 / 通用）+ 列表（最近 8 条，超出滚动）+ 底部「+ 新建」
- `Ctrl+Shift+S` 存（选中 → 存选中；无选中 → 存草稿全文），默认落当前项目
- 保存后 2 秒轻提示「已存到 此项目 · 改存通用」，一点即改
- AI 回复动作行加一枚「存为提示词」（`assistant-actions`，order 30）
- `Ctrl+Shift+P` 开面板（点圆点同效）
- 回车插入光标处；Alt+回车替换全文；右键/长按删除；双击编辑
- 存储 `~/.dsh/dsh-prompt-stash/store.json`，上限 500 条，超出按最久未用淘汰
- `prompt_stash` 工具：`list / save / search / remove`，`save` 收 `scope`（`global` / `workspace`）
- 中英双语，跟随 DSH 语言

不做（第一版）：

- 标签、分类树、导入导出向导、回收站、AI 润色、Skill 生成、云同步、会话级分档、批量迁移旧项目条目

## 五、交互与视觉规格

- 圆点：`--dsw-alias-bg-overlay` 底，`--dsw-alias-border-l1` 描边，1px，无阴影，无渐变；悬停时才浮现数字。
- 卡片：`--dsw-alias-bg-layer-1`，8px 圆角（只此一处圆角，不做卡片堆），1px 描边，不使用模糊（不是滚动中的遮罩，按用户级规则不糊 blur）。
- 行：两行结构——第一行正文前 60 字（`--dsw-alias-label-primary`），第二行灰字显示来源（草稿/选中/手写）与时间（`--dsw-alias-label-secondary`）。
- 动效：卡片 120ms 透明度 + 4px 位移，`prefers-reduced-motion` 时不做位移。
- 保存成功：圆点跳一下 + 数字 +1，不弹 toast。

## 六、技术路径（已验证的接口）

- 座位：`conversation.input.overlay`（会话作用域，无版面占用），组件 `position: fixed` 时 portal 到 `document.body`（DSH 该槽位明确要求）。
- 读草稿：`InputState.draft`（已发布状态，`useInput` 选择器）。
- 写草稿：`SessionInput.setDraft(text)`；插入用「读现有 + 拼接 + setDraft」保持光标语义。`insertQuote` 只适合引文，不用于普通插入。
- 快捷键：跟 `conversation.input.right` 的键盘仲裁一致，先做组件内 keydown，冲突时再走宿主 keymap。
- 存储与工具：与 dsh-todo-bar 同构（`ctx.webServer` + `ctx.tools` + 原子写）。

风险：`shell.overlay` 是 root 作用域，拿不到会话输入；因此**圆点必须从 `conversation.input.overlay` 渲染并 portal**，不能图省事挂全局浮层。

## 七、已确认的取舍（2026-11-25 02:30 用户答复）

| 问题 | 结论 |
| --- | --- |
| 分组 | 两档：**通用**（所有会话可见）/ **项目**（当前工作区）。不做会话级 |
| 回复存提示词 | 要。挂在 AI 回复的动作行里 |
| 上限 | 500 条，超出淘汰最久未用 |

### 分组的实现口径

- 「项目」键用 **workspace id**，不用 session id。理由：会话会被归档、会被 fork，绑 session 就等于把提示词绑在一条命很短的对象上；workspace 才是用户心里那个「项目」。
- 没有 workspace 的裸会话，项目档退化为通用档，界面不显示空白页。
- 项目被删或改名后留下的条目：不删数据，归到「旧项目」分组显示，可手动迁到通用。第一版只折叠显示，不做批量迁移。

### 存的默认落点

默认存进**项目**，因为带项目语境的提示词（路径、术语、客户名）挪到别处就是废的。

但默认不等于唯一出路：保存后圆点旁出现一行 2 秒的轻提示「已存到 此项目 · 改存通用」，点一下就改。这样主路径还是 1 步，纠错只要 1 次点击，不用开面板。

### 回复存提示词

- 座位：`conversation.chat.assistant-actions`（`order: 30`，排在现有 feedback 10、context-jump 20 之后）。
- 该座位给的是 `messageId` 加一组标准 props（`useConversation` / `useProjection` / `sessionId` 等），取正文要按 messageId 从会话投影里拿。
- **已验证（见 `VERIFY.md`）**：客户端只给 `messageId`，正文要从宿主侧读——`ctx.sessions.get()` → `snapshotEvents()` → 按 `data.message.id` 匹配 → 取 `content` 里 `text` 块拼 Markdown。要加一条宿主路由。
- 存进去的内容：完整 Markdown 原文，标题取首行前 40 字。长回复不截断存储，只在列表里显示首行。


## 八、怎么证明比竞品好用

同一批 10 条提示词，各做一次：

| 动作 | 度量 |
| --- | --- |
| 存一条刚写的草稿 | 按键次数 + 秒数 |
| 找到一条三个月前存的 | 秒数 + 是否需要鼠标 |
| 插入后继续打字 | 焦点是否丢、光标是否回到原位 |

目标：存 ≤ 1 键 0 次点击；取 ≤ 3 键；插入后焦点回输入框。
