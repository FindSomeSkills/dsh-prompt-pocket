# dsh-prompt-stash

**是一个口袋，不是一个库。** 角落一枚 24px 的圆点。按 `Ctrl+Shift+S`，你正在打的那段草稿就存进去了；点一条，它回到光标处。

**界面里不多出任何东西。** 没有侧栏入口，没有输入框上方那排胶囊，没有会挤压对话的面板。圆点不参与布局，飘着，还能拖。

## 存

| 你做什么 | 存什么 |
| --- | --- |
| 选中文字，按 `Ctrl+Shift+S` | 存选区 |
| 没选中，按 `Ctrl+Shift+S` | 存整段草稿，不用先复制 |
| 点 AI 回复上的 ⤓ | 存那条回复的 Markdown 原文 |

**保存从不弹窗。** 圆点闪一下，数字加一，你接着打字。下面一行小字告诉你存到哪了，顺手可以改。

## 存到哪

两个抽屉：

- **此项目** —— 同一个 workspace 下的所有会话都看得见。路径、客户名、写了一半的语境，存这里。
- **通用** —— 到哪儿都看得见。

按 workspace 分，不按会话分：会话会归档、会 fork，绑在一条会话上的提示词很快就没了家。没有 workspace 的裸会话自动退成通用，界面不留一个空标签页。

## 用

点圆点，或按 `Ctrl+Shift+P`。输入即过滤，`Enter` 插到光标处，`Alt+Enter` 用这条替换整段草稿。

**插入是一步撤销，而且不动草稿的其余部分。** 走的是输入框那套带修订号保护的插入，你原来插的引用 chip、挂的附件都留在原地。

## 润色，点的时候才润

**保存的时候绝不润色。** 存完那 2 秒的提示行里有「润色一下」，每条非回复的条目后面有 ✦。不点就不动任何字。

点开是原文和润色后并排，你选：用这版、放弃、再来一次。接受之后原文留在 `prior` 里，点一下就能退回。**失败或空结果绝不覆盖原文**，原样留着，提示行里写明。

从回复存进来的标为素材，没有 ✦：那是你特意要原样的。

润色用你当前默认模型，指令写死：同语言、保留每个 `{{变量}}`、路径、URL、代码块原样、不加步骤、长度不超过 1.3 倍。

## 上限

**最多 500 条。满了淘汰最久没用的那条。** 不弹窗，不留一堆你再也想不起来点开的东西。

存在 `$DSH_HOME/dsh-prompt-stash/store.json`，一个文件，原子写。文件坏了改名成 `.corrupt-<时间戳>.bak`，然后从空口袋继续。

模型通过 `prompt_stash` 工具读写同一份，说一句「把刚才那个存起来」就行，不用复制粘贴。

## 需要什么

- DeepSeek Harness `>= 0.2.0-rc.1`，Web profile：口袋挂在输入框里面，要用会话插槽
- Windows、macOS、Linux 跑同一份代码
- 桌面客户端没验证过

## 它不做什么

**没有标签、没有文件夹、没有导入向导、没有回收站。** 这些每一样都要求一个面板，而面板要求你每次保存都做一次决定。这个工具就是为了让你没有决定可做。
